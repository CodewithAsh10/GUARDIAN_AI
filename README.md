# Guardian AI: A Predictive Crime Intelligence Platform

## College EPICS Project: Module 1 (Crime Analysis, Intelligence & Interactive Dashboard)

### Overview

Guardian AI analyses 2017–2022 NCRB district-wise IPC crime data to produce trend analysis,
state/district comparisons, crime-category insights, historical hotspot identification and a
fully functional interactive web dashboard. The platform is designed to be modular so later
modules (crime prediction, safe-route optimisation) can be integrated without rewriting existing code.

### Module 1 Functionality (this development session)

| Feature | Description |
|---------|-------------|
| **Dataset loading & validation** | 5,322 district-year records, 142 independent crime categories, 6 years (2017–2022), 41 raw state variants normalised to 36 canonical names. All validation checks pass (0 duplicates, 0 negative counts, missing blanks treated as 0). |
| **Exploratory Data Analysis (EDA)** | Year-wise crime trends, state-wise rankings, district-level analysis, category distribution, category-wise yearly trends. |
| **Historical hotspot identification** | Transparent, explainable rule-based scoring: magnitude (0.6) + consistency (0.4) of top-N repeat appearances. Qualifies districts appearing in top-10 for >=3 of 6 years. |
| **Data visualisations** | 8 interactive Plotly figures (yearly trend, YoY % change, top states, top districts, category distribution, category pie, category yearly trend, hotspot ranking) and 8 PNG static exports saved to `visualisations/`. |
| **Interactive Geographical map** | District/state ranking alternative (boundary GeoJSON not bundled; user may provide a genuine GeoJSON to enable Folium choropleth). Maps faithfully state that district-level data does NOT identify exact streets or coordinates. |
| **Streamlit web dashboard** | Seven navigable pages (Overview, Crime Trends, State Analysis, District Analysis, Hotspot Intelligence, Geographical Intelligence, Data Explorer) with dark navy theme, interactive KPI cards, filterable charts, and a downloadable-filter CSV. |
| **Downloadable dataset** | `dashboard/pages/data_explorer.py` allows filtering by state/year/district/crime category and exporting the filtered result as CSV. |

### Dataset Source

- National Crime Records Bureau (NCRB), Ministry of Home Affairs, Government of India.
- Official portal: https://www.ncrb.mha.gov.in/crime-in-india-additional-table?year=2022&category=
- Six district-wise IPC crime files downloaded: 2017, 2018, 2019, 2020, 2021, 2022.
- Cleaned master CSV on disk: `dataset/processed/guardian_crime_master_2017_2022.csv`
  (5,322 rows × 152 columns).

### Important caveats (academic honesty)

- This dataset contains **district-level annual aggregates**, not exact crime coordinates.
- It cannot identify streets, coordinates, or individual incidents.
- Raw reported crime **counts are not crime risk**: no population data is available,
  so crime rates per 100,000 people cannot be computed from this dataset alone.
- The 2020 crime count jump may reflect reporting/pandemic changes, not a true surge.
- State names have year-variant spellings (e.g. 'Harayana'/'Delhi UT' normalised to
  'Haryana'/'Delhi'); normalisation is documented in `src.data_loader.NORMALISATION_MAP`.
- Reporting variations documented in `data_quality_note` column (e.g. West Bengal 2018 data
  substituted per NCRB workbook footnote; Puducherry aggregate row excluded from district records).

### Installation

1. Clone or ensure the project folder is at `GUARDIAN_AI/`.

2. Create Environment 
  `conda create -n guardian_ai python=3.11 -y`
  
  then

  `conda activate guardian_ai`

3. Install dependencies:

```bash
python -m pip install --force-reinstall --no-deps numpy==1.26.4 pyarrow==17.0.0
```
4. Launch the Streamlit dashboard:

```bash
  streamlit run dashboard/app.py
```

The app opens at http://localhost:8501. Use the sidebar radio to navigate pages.

### How to execute the notebook

The notebook `notebooks/01_crime_analysis.ipynb` contains 27 cells (13 code + 14 Markdown)
covering all 14 required sections: project introduction, imports, data loading, inspection,
quality checks, cleaning, EDA, crime trends, state analysis, district analysis, category analysis,
hotspot identification, visualisations, and findings/conclusion. Run cell-by-cell or use
`jupyter nbconvert --to notebook --execute --inplace notebooks/01_crime_analysis.ipynb`.

### How to reproduce the complete analysis

1. `pip install -r requirements.txt`
2. Open `jupyter notebook` and run `notebooks/01_crime_analysis.ipynb` from beginning to end.
3. Execute `streamlit run dashboard/app.py` to launch the interactive dashboard.
4. Review `tests/test_module1.py` results (26 tests, all pass).
5. Static PNG charts are in `visualisations/`. Validation summary is in `src/data_validation.py`.

### Known limitations (documented for faculty review / viva)

| Limitation | Explanation |
|------------|-------------|
| No population data | Cannot compute crime rates / risk per 100,000. Raw counts ≠ risk. |
| District-level annual data | Cannot identify streets/coordinates or individual incidents. |
| Reporting variations | NCRB workbooks may contain notes (e.g. WB 2018 data substitution) affecting counts. |
| State-name variants | Same UT/statelabelled differently across years (see normalisation map). |
| Single module only | Machine-learning prediction and safe-route optimisation are intentionally omitted per project scope. |
| Geographical map | Choropleth requires an externally-provided boundary GeoJSON; none bundled. |
| No data behind points | Visualisations show area-level aggregates; point-density or street-level maps are not generated. |
